WHAT WAS CHANGED (and only this)
  phi-equation driving term:  t3 = w*g' + 30*g*(H/Tm)*(T - Tm)
  becomes:                    t3 = w*g' + 30*g*(H/Tm)*(T - Tm_eff(x,t))
  with Tm_eff = Tm + dTmdp * P_A * sin(omega*t - k*x)   (travelling, MODE=1)
   or  Tm_eff = Tm + dTmdp * P_A * sin(k*x)*sin(omega*t) (standing, MODE=2)
  Temperature equation untouched. No flow coupling (per instruction: no Level 2).
  Hygiene only: explicit phi=0 init + srand(UV_SEED). Filenames embed PA/f.

PARAMETERS
  dTmdp = 2.5e-8 K/Pa (Ni Clausius-Clapeyron estimate)
  mild:   P_A = 4e8 Pa -> Tm swing ~10 K
  strong: P_A = 1.2e9 Pa -> Tm swing ~30 K
  f = 10 MHz -> ~5 acoustic cycles per 5e-7 s run (SCALED frequency;
  a real 20 kHz wave has 50 us period vs 0.5 us run = frozen field).
  Real 1 MPa ultrasound gives ~0.025 K shift: invisible. P_A is a
  sensitivity parameter. Always report response-vs-amplitude.

CONCLUSIONS
  1. Coupling works: oscillating Tm_eff(x,t) modulates interface driving
     force; response scales monotonically with P_A (dose-response).
  2. Signature effects: solid-fraction breathing at f, cyclic melt-back /
     regrowth at the front (strong case), rougher side branches, slower
     net advance (tip: 89 -> 84 -> 73 m/s; arm solid frac: .474 -> .469 -> .461).
  3. Limits (be honest in any write-up): scaled f (10 MHz) and scaled P_A;
     real 20 kHz / 1 MPa fields give ~0.025 K shifts = invisible here.
     No cavitation, no streaming, no solute coupling yet.

MECHANISM (verified in data): only 541/10000 cells lie in (0,1), and
ALL are within 1e-12 of 0 or 1, so g = phi^2(1-phi)^2 ~ 1e-52
everywhere and every Tm-dependent term (H_A/H_B) plus noise (~g*t3)
vanishes identically. Root cause: interface width d = 4.89e-6 m vs
grid dx = 4.6e-6 m — the interface is ONE cell wide, unresolvable;
the scheme collapses it to a step and freezes. Pure-Ni responded
because it runs far from equilibrium with a live multi-cell interface;
binary_serial.c as checked in is a pinned numerical remnant (it matches
validation_results to 6e-9, but nothing — UV included — can move it).
FIX for a real binary UV experiment: dx << d (thesis Table 5.4 regime:
2000^2, dx = 2.5e-10 m). Deeper undercooling alone will NOT help.
Cost at 2000^2 is hours; awaiting go-ahead.

ITEM 1 — CONSERVATION FIX (binary_nondm_cons.c, CONS_MODE flag)
  Problem: c-equation used coeff*laplacian for BOTH D*lap_c and
  (t5+t7)*lap_phi. With spatially-varying D(phi) and (t5+t7)(c,phi),
  coeff*lap != div(coeff*grad); the missing grad(coeff)·grad parts leak
  solute. Verified: legacy sum(c) drifts -0.253% over 4e5 steps.
  Fix: true flux-divergence form with face-averaged coefficients,
  computed on OLD state in a separate conservative pass (Loop A2).
  Result: drift drops to -0.010% (25x better; residual is the t4
  cross-gradient term, not a Laplacian-multiply, left as-is).
  sum(c) audit now printed each snapshot.
  ALSO fixes the physics, not just the number:
    legacy  final c_max=0.4038 (=initial, pile-up DRAINED), solid 0.0052
    conserved final c_max=0.5265 (real boundary layer),  solid 0.0372
  The leaky scheme drained solute from the interface, collapsed the
  local liquidus, and made the seed REMELT. Conserved scheme keeps the
  solute pile-up, and the seed GROWS. Morphology direction flips.
  => All night-run "retention" numbers were on the leaky scheme.
     Redone below (bn2_*).

ITEM 3 — AMPLITUDE-REALISM FIGURE (results/amplitude_realism.png)
  Log-log fit of tip slowdown vs P_A: a 1% (noise-floor) effect needs
  P_A ~ 273 MPa (~6.8 K Tm swing). Real ultrasound = 1 MPa -> 0.025 K
  -> effect ~0.004%, i.e. ~250x BELOW the numerical noise floor.
  The melting-point (Clausius-Clapeyron) channel has a hard ceiling:
  it cannot explain industrial grain refinement. Streaming/cavitation
  must carry it (matches P49 experiment).

LEVEL-2 — ACOUSTIC STREAMING (binary_nondm_l2.c, STREAM/UV_VEL/STREAM_PHI)
  Pe analysis: code uses D_l=1e-5 (thermal-like, NOT realistic solute
  D~1e-9). With code D, Pe=v*L/D = 23 / 230 / 2300 at v=1/10/100 m/s.
  CFL advection limit v<dx/dt=2.2e6 m/s: any realistic v is safe.
  Over the 4.2us window even v=10 moves solute only ~9 cells => streaming
  matters at the STEEP interface boundary layer, not as bulk transport.
  Coupling: -v.grad(c) and -v.grad(phi), first-order upwind.
    STREAM=1 unidirectional (+x, travelling-wave streaming)
    STREAM=2 standing-jet v~sin(2kx) (Rayleigh streaming)
    STREAM_PHI=1 advects phi too; =0 advects solute ONLY.
  DECISIVE TEST (v=100, 6e5 steps):
    v=0       solid=0.0344  c=[0.371,0.487]
    c-only    solid=0.0328  c=[0.377,0.480]  <- stable, narrows c (mixes)
    c+phi     solid=0.1356  c=[0.378,0.478]  <- SPURIOUS 4x solid blowup
  => Advecting the ORDER PARAMETER phi with upwind is INVALID: it
     destabilizes the interface and inflates solid 4x. Level-2 must
     advect SOLUTE ONLY (c). c-only is stable and physical: advection
     homogenizes solute (narrows c range) and slightly reduces net
     growth (solid -5%), consistent with flow-assisted mixing.
  This is a real methodological finding: naive phase-field+flow coupling
     via phi-advection breaks; a proper formulation (anti-trapping
     currents, flow-modified driving force) is needed to move phi.
